# Analysis and Visualization Scripts

This directory contains higher-level analysis and visualization scripts used to generate comparative propagation figures and frequency-domain analysis outputs.

## Included Analysis Types

- Distance comparison overlays
- Indoor vs outdoor comparisons
- Obstruction comparison analysis
- FFT-based frequency-domain analysis
- Bandwidth comparison analysis
- CIR overlay generation
- Frequency-selective fading visualization

## Visualization Goals

The generated figures were used to:

- Compare propagation environments
- Visualize multipath behavior
- Analyze temporal resolution trends
- Demonstrate frequency-selective fading effects
