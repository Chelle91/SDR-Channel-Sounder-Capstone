# Signal Processing Scripts

This directory contains scripts responsible for extracting and processing wireless channel metrics from captured IQ data.

## Processing Operations

Implemented processing stages include:

- Cross-correlation
- CIR extraction
- PDP generation
- RMS delay spread estimation
- Coherence bandwidth estimation
- CSV export and figure generation

## Design Approach

Offline signal processing was used throughout the project to simplify debugging, enable repeatability, and accelerate experimental iteration.
