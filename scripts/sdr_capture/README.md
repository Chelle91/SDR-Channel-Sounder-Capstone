# SDR Capture Scripts

This directory contains scripts responsible for SDR transmission and IQ capture operations.

## Functionality

Implemented capabilities include:

- PN sequence generation
- Continuous SDR waveform transmission
- Raw IQ sample capture
- UHD Python API interfacing

## Hardware Platform

- Ettus USRP B200 SDRs
- 2.45 GHz ISM band operation
- USB 3.0 connectivity
