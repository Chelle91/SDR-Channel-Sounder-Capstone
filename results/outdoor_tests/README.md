# Outdoor Propagation Experiments

This directory contains outdoor propagation experiments used to compare indoor and outdoor wireless channel behavior.

## Scenarios

- `outdoor_los/`
- `outdoor_obstructed/`

## Objective

The outdoor experiments evaluated:

- Environmental propagation differences
- Obstruction-induced multipath effects
- Relative correlation floor behavior
- Outdoor CIR structure

## Key Observation

Outdoor line-of-sight environments generally produced cleaner dominant propagation paths, while obstruction scenarios increased multipath complexity and elevated correlation floors.
