# Indoor Distance Sweep Experiments

This directory contains indoor line-of-sight propagation experiments performed at multiple transmitter-to-receiver separations.

## Scenarios

- `indoor_6ft/`
- `indoor_10ft/`
- `indoor_15ft/`

## Objective

The goal of these experiments was to evaluate how spatial separation influenced:

- Channel impulse response structure
- RMS delay spread
- Correlation floor behavior
- Multipath characteristics

## Key Observation

The experiments demonstrated non-monotonic propagation behavior, highlighting the sensitivity of indoor multipath environments to small positional and geometric changes.
