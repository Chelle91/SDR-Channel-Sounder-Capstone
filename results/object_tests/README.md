# Object Obstruction Experiments

This directory contains controlled obstruction experiments used to evaluate how physical materials affected wireless propagation behavior.

## Scenarios

- `baseline_los/`
- `cardboard_obstruction/`
- `wood_obstruction/`
- `human_obstruction/`
- `aluminum_obstruction/`

## Objective

The experiments evaluated how obstruction materials altered:

- CIR peak structure
- Reflection behavior
- Correlation floor levels
- Multipath spread

## Key Observation

Highly reflective materials such as aluminum produced stronger secondary reflections and elevated correlation floors compared to softer obstruction materials.
