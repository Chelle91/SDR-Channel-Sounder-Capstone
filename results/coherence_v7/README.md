# Coherence Bandwidth Analysis

This directory contains coherence bandwidth estimation results derived from FFT-based frequency-domain channel analysis.

## Contents

- `coherence_bandwidth.csv`
  Aggregate coherence bandwidth metrics.

- `coherence_bandwidth.png`
  Original coherence bandwidth visualization.

- `coherence_bandwidth_v2.png`
  Updated visualization with improved scaling and readability.

## Objective

The analysis estimated coherence bandwidth trends across experimental scenarios to evaluate frequency-selective propagation behavior.
